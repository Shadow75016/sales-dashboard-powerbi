# Sales Dashboard – Power BI

## Description

Ce projet consiste à créer un tableau de bord interactif avec **Microsoft Power BI** afin d’analyser les ventes, les bénéfices et les performances commerciales d’une entreprise.

Le dashboard permet d’explorer les résultats selon plusieurs dimensions :

- la période ;
- la région ;
- la catégorie de produit ;
- le segment client ;
- les ventes ;
- les bénéfices ;
- le nombre de commandes.

L’objectif est de transformer des données commerciales brutes en indicateurs visuels faciles à comprendre.

## Objectifs du projet

- Analyser le chiffre d’affaires global.
- Suivre l’évolution des ventes dans le temps.
- Comparer les performances des régions.
- Identifier les catégories de produits les plus performantes.
- Analyser les bénéfices générés.
- Créer un outil d’aide à la décision simple et interactif.

---

## Technologies utilisées

- **Power BI Desktop**
- **Power Query**
- **DAX**
- **Excel**
